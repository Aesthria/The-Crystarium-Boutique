# Support

Start with [Installation](docs/INSTALLATION.md), [Features](docs/FEATURES.md), [Design Import](docs/DESIGN-IMPORT.md), and [Troubleshooting](docs/TROUBLESHOOTING.md).

Once the repository is public, use its GitHub issue forms for:

- reproducible functional bugs,
- incorrect item or acquisition data,
- visual or interface issues, and
- feature requests.

Include the TCB version, relevant Dalamud version, minimal reproduction steps, expected and actual results, and the Item ID when applicable. For appearance or restoration problems, include whether Glamourer and Penumbra were installed and enabled. For visual problems, include the selected theme, relevant scale settings, window size, and a tightly cropped screenshot.

Do not post access tokens, credentials, account details, character information, chat, private filesystem paths, complete configuration folders, or unredacted logs. A short redacted log excerpt is preferable to a full log.

No public Discord server or support email is currently designated. Do not use an unofficial contact as a project support channel.
